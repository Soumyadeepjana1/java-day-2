boolean: Stores true or false (1 bit). 
char: Stores a single 16-bit Unicode character. 
byte: 8-bit signed integer, range -128 to 127. 
short: 16-bit signed integer, range -32,768 to 32,767. 
int: 32-bit signed integer, default for whole numbers, range -2^31 to 2^31-1. 
long: 64-bit signed integer, for large numbers, range -2^63 to 2^63-1.
float: 32-bit single-precision floating-point decimal. 
double: 64-bit double-precision floating-point decimal, default for decimals.
